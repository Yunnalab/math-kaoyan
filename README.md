## 说明

- **大文件走 Git LFS**：超过 GitHub 100 MiB 硬限制的 PDF（《基础过关660》高数篇、《高数基础篇》正文、张宇 1000 题试题册）由 Git LFS 托管，见 `.gitattributes`。首次使用前先装好 `git-lfs` 并执行 `git lfs install`。
- **2024 年真题/解析**目前只有 `docx` 原件（数一、数二、数三各两份），其余年份均为 PDF。
- **早期年份存在多年合并册**：数二 1989–2004、2005–2013 两本，数三 1987–1996、1997–2009、2010–2022 三本，数一另有可直接打印的两年段合集。
- **2026 年真题**来自考后公开来源，数一 / 数二为题目 + 参考答案，数三为无水印真题 + 简版答案。

资料仅用于个人复习，版权归原作者与出版方所有。
